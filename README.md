## 📋 Sobre o Projeto

O **Support Dashboard** simula um painel real de acompanhamento de chamados utilizado por equipes de suporte técnico. Exibe indicadores em tempo real com armazenamento local no navegador, sem necessidade de backend.

---

## ✨ Funcionalidades

| Recurso | Descrição |
|---|---|
| 📝 Cadastro de chamados | Registre novos chamados diretamente pelo painel |
| 📈 Indicadores em tempo real | Visualize métricas atualizadas automaticamente |
| ✅ Chamados resolvidos | Acompanhe o histórico de resoluções |
| ⏳ Chamados pendentes | Monitore o que ainda está em aberto |
| 🎯 Taxa de resolução | Indicador percentual de desempenho da equipe |
| 💾 Persistência local | Dados salvos via LocalStorage |

---

## 🎯 Casos de Uso

Projeto pensado para simular o dia a dia de equipes como:

- 🖥️ Help Desk
- 🛠️ Service Desk
- 🔧 Suporte Técnico
- 🏗️ Operações de TI
